Hotel and Hotel Management Website

DineLink OS

A QR ordering, staff operations, payment confirmation, and event booking platform for modern hotels.

Project presentation deck
Problem

Hotels need faster ordering and clearer operations.

Manual order delays

Staff take orders repeatedly, room context can be missed.

Payment confusion

Cash and online payment need different confirmation flows.

Kitchen coordination

Kitchen needs a live queue, not verbal handoffs.

Event planning

Special event requests need structured requirements and follow-up.

Solution

DineLink OS connects guests, staff, kitchen, and admin.

1

Customer

Scans QR, orders food, chooses payment, tracks history.

2

Staff

Handles orders, payments, service requests, and rooms.

3

Kitchen

Receives confirmed orders and updates preparation status.

Core Features

What the project includes

  • Role-based login for customer, admin, service staff, and kitchen.
  • QR-based room menu and cart ordering.
  • Cash code payment flow with admin confirmation.
  • Live kitchen and service staff dashboards.
  • Menu, category, staff, guest, room, and order management.
  • Special events module with automatic budget estimate.
Payment Flow

Cash payment becomes confirmed only after admin approval.

Online

Order is marked paid and enters normal order flow.

Cash

Customer gets a CASH code. Admin searches the code and clicks Mark Paid.

Before Mark Paid

Order is payment pending and not treated as confirmed.

After Mark Paid

Payment successful, order confirmed, kitchen receives it.

Special Events

Customers can plan birthdays, parties, and custom events.

Requirements

Event type, date, guest count, food, decor, contact, room or area.

Food selection

Available hotel menu chips plus custom dish requirements.

Budget estimate

Auto bill estimate based on guests, event type, decor, and setup.

Admin follow-up

Admin sees requests, status, notes, and customer details.

Architecture

Full-stack MERN-style implementation

Frontend

React, Vite, protected routes, auth context, cart context, responsive UI.

Backend

Node.js, Express, REST APIs, JWT middleware, role authorization.

Database

MongoDB models for users, menu, orders, events, rooms, service requests.

Realtime

Socket.IO updates for orders, payment completion, and service operations.

Demo Flow

Recommended walkthrough

  • Login as customer and place a cash order.
  • Copy the generated cash code.
  • Login as admin and open Payments.
  • Search code, click Mark Paid, and confirm order.
  • Open Kitchen to see the live order queue.
  • Submit a Special Event request and review it in Admin Events.
Impact

DineLink OS shows a complete hotel workflow.

The project demonstrates customer ordering, staff control, payment handling, realtime kitchen operations, customer history, and event planning in one connected application.
