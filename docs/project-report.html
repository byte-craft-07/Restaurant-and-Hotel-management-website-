Hotel and Hotel Management Website

DineLink OS

A full-stack hotel ordering and operations platform with QR menu ordering, role-based dashboards, cash/online payment flow, customer order tracking, and special event booking.

Frontend React, Vite, Tailwind-style utility UI, Framer Motion
Backend Node.js, Express, MongoDB, JWT, Socket.IO
Users Customer, Admin, Service Staff, Kitchen Staff

1. Project Overview

DineLink OS is designed for hotels that want a modern digital ordering system without losing staff control. Customers can scan a QR code, browse the menu, add items to cart, pay online or choose cash, and track order history. Staff members manage orders, rooms, kitchen preparation, customers, payments, and special event requests.

2. Problem Solved

Slow manual ordering QR ordering reduces wait time and makes room context clear.
Payment confusion Online and cash flows are separated, with cash code confirmation.
Kitchen coordination Live dashboards show pending, accepted, preparing, and served orders.
Event planning Customers can request birthday or party bookings with preferences.

3. Main Features

Customer Features

Customers can register, login, open a QR-linked menu, add menu items, choose online or cash payment, track order history, and submit special event requirements.

QR menu Cart Cash code My Orders Special Events

Admin Features

Admins can manage menu items, categories, orders, customers, staff, rooms, cash payments, and special event requests. Admins can search a cash code and confirm payment, which then confirms the order.

Dashboard Orders Payments Events Staff Rooms

Kitchen and Service Staff Features

Kitchen staff view live order queues and update preparation status. Service Staffs handle service requests and can update active order statuses.

4. Payment Workflow

Customer selects menu items and opens the cart.
Customer chooses either online payment or cash payment.
For online payment, the order is immediately marked paid.
For cash payment, the system generates a unique code such as CASH-402646.
Admin enters the code in the Payments panel and clicks Mark Paid.
After Mark Paid, the order becomes confirmed and enters the kitchen flow.

5. Special Events Module

The Special Events module lets customers request birthdays, anniversaries, office parties, family functions, or other events. Customers can choose available hotel menu items, add custom food requirements, select room or area preferences, choose decoration setup options, and see an automatic estimated bill before submission.

Field Purpose
Event Type Birthday, anniversary, office party, family function, etc.
Guests and Date Used for planning and automatic cost estimation.
Food Preferences Selectable menu chips plus custom typed requirements.
Decoration Preferences Selectable options such as cake setup, balloons, stage, music.
Room / Area Customer can select a room or type a custom area request.
Estimated Bill Auto-calculated based on guests, event type, and preferences.

6. Technical Architecture

Layer Details
Frontend React app with protected routes, role-aware pages, cart context, auth context, API service, and responsive UI components.
Backend Express REST API with controllers, models, middleware, and routes for auth, menu, orders, payments, events, rooms, staff, and analytics.
Database MongoDB collections for users, menu items, categories, orders, rooms, service requests, and event bookings.
Realtime Socket.IO emits order creation, status updates, service requests, and payment completion updates.

7. Security and Access Control

JWT authentication protects private routes. Role-based authorization separates customer, admin, service staff, and kitchen access. Event booking submission requires a customer login. Admin-only functions such as staff management, payment confirmation, and event management are protected.

8. Recommended Demo Flow

Login as customer and open the menu.
Add items and choose cash payment.
Copy the generated cash code.
Login as admin and open Payments.
Search the cash code and click Mark Paid.
Open My Orders or Kitchen to see the confirmed order.
Open Special Events and submit a birthday or party request.
Admin reviews the request in the Events panel.

9. Conclusion

DineLink OS is a practical hotel management project covering real guest ordering, staff operations, payment confirmation, and event planning. It demonstrates both customer experience and hotel back-office control in one connected system.
